# Carta Interactiva Romántica – Web Experience
Aplicación web estática enfocada en la creación de una experiencia interactiva mediante manipulación del DOM, animaciones CSS y diseño responsive.
El proyecto implementa una galería dinámica con visualización tipo carta y efectos visuales modernos orientados a mejorar la experiencia de usuario (UX).

🧠 Objetivo Técnico
* Este proyecto fue desarrollado para practicar y demostrar:
* Manipulación del DOM con JavaScript
* Gestión de eventos (onclick)
* Control dinámico de estilos (display, animaciones)
* Animaciones y transiciones CSS
* Diseño responsive con media queries
* Estructuración semántica en HTML5
* Organización modular básica de componentes visuales

⚙️ Stack Tecnológico
* HTML5 → Estructura semántica
* CSS3
* Animaciones (@keyframes)
* Transiciones
* Glassmorphism
* Responsive Design
* JavaScript (Vanilla)
* Event handling
* Query selectors
* Manipulación de clases y estilos
* Google Fonts → Tipografía estilo carta

Componentes principales:
* Carta inicial interactiva
* Animación de apertura
* Evento de activación
*Galería de recuerdos
* Renderizado en grid responsive
* Eventos dinámicos para mostrar contenido
* Componente “Letter View”
* Se muestra dinámicamente
* Animación de aparición
* Efecto visual tipo carta

Compatibilidad
* Chrome
* Edge
* Firefox
* Navegadores móviles modernos
